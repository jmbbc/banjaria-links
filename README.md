# Banjaria Court — Pusat Pautan Penduduk

Halaman statik untuk Badan Pengurusan Bersama Banjaria Court. Mengandungi 14 pautan urusan penduduk, carian, kategori berwarna dan paparan mesra telefon.

## Pratonton
Buka `index.html` dalam pelayar. Tiada pemasangan pakej atau proses build diperlukan. Font Google memerlukan sambungan internet; font sistem digunakan sebagai fallback.

## Kemas kini pautan
Edit senarai `links` dalam `index.html`. Kekalkan URL yang disahkan oleh pihak pengurusan. Halaman ini tidak menerima atau menyimpan data borang; pautan membawa ke penyedia masing-masing.

## Hosting
- cPanel: salin `index.html` ke folder domain seperti `public_html`.
- GitHub Pages: dalam Settings → Pages, pilih Deploy from a branch → main → / (root), jika pelan dan visibility repository menyokongnya.
- Domain sendiri boleh dikonfigurasi selepas hosting diaktifkan.

GitHub Pages belum diaktifkan. Tiada nombor akaun bayaran, kata laluan atau credential hosting diperlukan dalam repository ini.
